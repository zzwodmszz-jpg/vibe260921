# PRD: 개발자 프로필 웹사이트 (DemoPort)

## 1. 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | DemoPort |
| 개발자 | 재이 |
| 이메일 | zzwodmszz@gmail.com |
| 주 개발 분야 | 바이브코딩, Python, HTML5 |
| 문서 상태 | 초안 (v0.1) |

개발자 **재이**를 소개하고, 작업물(포트폴리오)을 보여주며, 연락할 수 있는 창구 역할을 하는 단일 페이지 프로필 웹사이트를 만든다.

## 2. 목적과 목표

### 목적
- 재이의 개발 역량과 작업물을 한곳에서 보여주는 온라인 명함을 만든다.
- 방문자가 쉽게 연락할 수 있도록 한다.

### 목표
- 방문 후 30초 안에 "누구이고, 무엇을 하는 개발자인지" 파악할 수 있다.
- 모바일, 태블릿, 데스크톱 어디서나 깨지지 않고 읽힌다.
- 서버 없이 정적 파일만으로 배포할 수 있다.

### 비목표 (이번 범위 아님)
- 로그인, 회원가입, 관리자 페이지
- 블로그 CMS, 댓글 기능
- 백엔드 서버와 데이터베이스

## 3. 대상 사용자

| 사용자 | 방문 이유 | 원하는 것 |
|--------|-----------|-----------|
| 채용 담당자 / 협업 제안자 | 개발자 역량 확인 | 기술 스택, 대표 프로젝트, 연락처 |
| 동료 개발자 / 학습자 | 작업물 구경, 교류 | 프로젝트 예시, 사용 도구 |
| 프로젝트 의뢰인 | 외주·협업 문의 | 할 수 있는 일, 문의 방법 |

## 4. 핵심 콘텐츠

### 4.1 소개 (Hero)
- 이름: 재이
- 한 줄 소개: 바이브코딩으로 아이디어를 빠르게 동작하는 결과물로 만드는 개발자
- 행동 버튼: "프로젝트 보기", "연락하기"

### 4.2 About
- 개발자 소개 글 (3~5문장)
- 바이브코딩(AI와 함께 만드는 개발 방식)에 대한 관점과 작업 방식

### 4.3 기술 스택
| 분야 | 내용 |
|------|------|
| 바이브코딩 | AI 코딩 도구를 활용한 빠른 프로토타이핑과 반복 개선 |
| Python | 자동화 스크립트, 데스크톱 게임 등 |
| HTML5 | 시맨틱 마크업, Canvas, CSS3, JavaScript 기반 웹 |

### 4.4 프로젝트 (포트폴리오)
카드 형태로 나열하며, 각 카드는 제목, 한 줄 설명, 사용 기술, 링크(데모/소스)를 가진다.

초기 프로젝트 후보 (재이가 이미 만든 작업물):
1. **뱀 게임 (Python)**: 사람과 AI 뱀이 사과를 두고 경쟁하는 tkinter 게임
2. **테트리스 (HTML5/CSS3/JavaScript)**: Canvas 기반 브라우저 게임

### 4.5 연락처
- 이메일: zzwodmszz@gmail.com (클릭 시 `mailto:` 연결)
- 이메일 주소 복사 버튼

## 5. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|----|----------|----------|
| F-01 | 단일 페이지에 Hero, About, 기술 스택, 프로젝트, 연락처 섹션을 표시한다 | 필수 |
| F-02 | 상단 내비게이션으로 각 섹션에 부드럽게 스크롤 이동한다 | 필수 |
| F-03 | 프로젝트를 카드 그리드로 보여주고 링크를 제공한다 | 필수 |
| F-04 | 이메일 링크(`mailto:`)와 복사 버튼을 제공한다 | 필수 |
| F-05 | 반응형 레이아웃 (모바일 / 태블릿 / 데스크톱) | 필수 |
| F-06 | 다크/라이트 테마 전환 (시스템 설정 기본 반영) | 선택 |
| F-07 | 스크롤 시 섹션이 나타나는 가벼운 애니메이션 | 선택 |

## 6. 비기능 요구사항

- **성능**: 외부 라이브러리 없이 HTML, CSS, JavaScript만 사용하고, 초기 로딩은 1초 안팎을 목표로 한다.
- **접근성**: 시맨틱 태그 사용, 이미지 `alt`, 키보드 탐색, 충분한 색 대비(WCAG AA)를 지킨다.
- **호환성**: 최신 Chrome, Edge, Safari, Firefox.
- **SEO**: `title`, `meta description`, Open Graph 태그를 설정한다.
- **유지보수**: 프로젝트 목록을 데이터(배열)로 분리해 항목 추가가 쉽도록 한다.

## 7. 기술 스택

- HTML5 (시맨틱 마크업)
- CSS3 (Flexbox, Grid, CSS 변수, 미디어 쿼리)
- Vanilla JavaScript (테마 전환, 스크롤, 클립보드)
- 배포: GitHub Pages 등 정적 호스팅
